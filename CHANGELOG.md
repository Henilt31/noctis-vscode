## [0.1.0] - 2026-10-06

### Added
- **Noctis**: Initial release of the core balanced dark theme engineered for deep work.
- **Theme Variants**:
  - `Noctis` - Default balanced dark workspace with astral indigo accents.
  - `Noctis Crimson` - Warm obsidian darkness with restrained crimson accents.
  - `Noctis Violet` - Cosmic amethyst depth with luminous violet tones.
  - `Noctis Midnight` - True-dark OLED-optimized obsidian variant.
- **Workbench Styling**:
  - Comprehensive workbench coverage across 340+ UI tokens including editor, tabs, sidebars, activity bar, status bar, command center, notifications, debuggers, diff editor, and breadcrumbs.
  - Layered surface hierarchy (`#08090C`, `#0B0D11`, `#101319`, `#151922`).
- **Syntax Highlighting**:
  - Specialized TextMate scopes for TypeScript, JavaScript, Python, React/JSX, Go, Rust, C/C++, Java, C#, PHP, HTML, CSS, SCSS, JSON, YAML, Markdown, SQL, and Shell/Bash.
  - Restrained, accessible semantic hierarchy with distinguishable operators, constants, types, and keywords.
- **Integrated Terminal & Git Colors**:
  - Tuned ANSI 16-color palette for terminal sessions.
  - Clear diff editor, conflict markers, and Git file status decorations.
- **Preview Environment**:
  - Sample `demo/` workspace files across 10 programming languages.
