# 🖤 Noctis — A VS Code Theme

> *A quiet place for loud ideas.*

### What is Noctis?

Noctis is a dark Visual Studio Code theme engineered for deep work and late-night development sessions.

Instead of pitch-black voids or high-saturation neon accents, Noctis relies on layered obsidian surfaces, soft contrast, and a calm chromatic hierarchy. The editor stays readable, the interface recedes into the background, and your focus stays entirely on the problem in front of you.

### Why You'll Like It

- **Subtle surface depth** — Four calibrated tiers of dark surfaces provide physical structure without harsh borders.
- **Calm, readable syntax** — Semantic colors guide your eyes through functions, types, and variables without rainbow noise.
- **Soft contrast balance** — High foreground clarity paired with gentle backgrounds that remain comfortable across long stretches of code.
- **Cohesive workbench chrome** — The editor, sidebar, tabs, terminal, Git diffs, and popups feel like one continuous thought.
- **Zero unnecessary friction** — No distracting glow effects, no harsh alerts, and no competing UI elements.

### How to Install and Use

Noctis is currently distributed as an open-source project directly from this repository. You can package and install it locally in two minutes:

```bash
# 1. Clone the repository
git clone https://github.com/Henilt31/noctis-vscode.git
cd noctis-vscode

# 2. Package the extension
npx @vscode/vsce package

# 3. Install into VS Code
code --install-extension noctis-theme-0.1.0.vsix
```

Once installed:

1. Open Visual Studio Code.
2. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on macOS) to bring up the Command Palette.
3. Type **Preferences: Color Theme** and press `Enter`.
4. Select **Noctis**.
5. Start coding.

### The Idea Behind Noctis

A great code editor should feel almost invisible while you work. It shouldn't constantly remind you that it's there with intense borders or jarring status bars. Noctis was crafted around the belief that contrast should serve navigation, color should clarify logic, and darkness should provide space for deep thinking.

### Built Around

- Layered obsidian and charcoal surfaces
- Restrained astral indigo and sky cyan primary guidance
- Crisp, distinguishable syntax scopes for major programming languages
- Dark integrated terminal palette with clean ANSI values
- Soft, readable comments that never vanish into the background
